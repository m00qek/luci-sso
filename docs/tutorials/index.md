# Tutorials

Tutorials are lessons that take the reader by the hand through a series of steps to complete a project of some kind. They are learning-oriented.

---

## 🏁 Getting Started
*   [First SSO Login: Public IdP](first-sso-login.md) - Enable SSO using a public identity provider (Google). Requires a domain name and a publicly trusted certificate.
*   [First SSO Login: Self-hosted IdP](pocket-id-sso-login.md) - Enable SSO using Pocket ID on your LAN. No external services or public infrastructure required.
*   [Building from Source](building.md) - Learn how to use the Dockerized SDK to build your first IPK.
*   [Developer Onboarding](dev-onboarding.md) - Set up the local development environment and run your first test.
